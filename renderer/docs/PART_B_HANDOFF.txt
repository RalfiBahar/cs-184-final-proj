HOW TO EXPLAIN THE MATH
The phase function is a probability density over outgoing directions. HG's g
is the expected cosine of the scattering angle: zero is isotropic, positive
values favor continuing forward, negative values favor reversing direction.
With traveling directions and mu=dot(incoming,outgoing):
  p(mu) = (1-g^2) / [4*pi*(1+g^2-2*g*mu)^(3/2)].
The sampler draws mu by the inverse CDF and phi uniformly, then rotates the
sample around the incoming direction using an orthonormal frame. At g=0 it
samples isotropically. Near zero it uses an algebraically equivalent inverse
CDF that avoids cancellation; it does not silently set a nonzero g to zero.
Sampling matches p, so value/pdf equals 1 for continuation.

A histogram of mu measures density in one dimension, while p is per unit solid
angle. Integrating out azimuth contributes 2*pi. That is why the plotted
reference is 2*pi*p(mu), not p(mu).

Direct lighting estimates Li * phase * Tr / lightPdf, then the caller multiplies
by current throughput. There is no surface cosine at a volume point. Opaque
visibility gives zero behind a blocker; Tr models attenuation only along the
clipped medium segment. The inherited point-light sample_L convention returns
its stored RGB value without inverse-square scaling; B preserves this API
rather than changing A's scene calibration.
